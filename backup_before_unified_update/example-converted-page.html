貧血診斷與治療

完整的貧血管理指南

什麼是貧血？

貧血是指血液中紅血球數量或血紅素濃度低於正常值的狀態。這會導致身體組織無法獲得足夠的氧氣，引起各種症狀。

正常血紅素值

  • • 成年男性：13.5-17.5 g/dL
  • • 成年女性：12.0-15.5 g/dL
  • • 孕婦：11.0 g/dL 以上

常見類型

缺鐵性貧血

最常見的貧血類型

維生素 B12 缺乏性貧血

巨球性貧血的一種

慢性疾病性貧血

貧血常見症狀

疲勞無力

容易感到疲倦，體力不足

心悸氣喘

心跳加快，容易喘息

面色蒼白

皮膚、眼瞼內側蒼白

診斷檢查

血液常規檢查 (CBC)

基本的血液檢查，包含：

  • • 血紅素 (Hemoglobin)
  • • 血球容積比 (Hematocrit)
  • • 紅血球數量 (RBC count)
  • • 平均紅血球體積 (MCV)

進階檢查

鐵質相關
  • • 血清鐵 (Serum Iron)
  • • 鐵蛋白 (Ferritin)
  • • 總鐵結合力 (TIBC)
維生素檢查
  • • 維生素 B12
  • • 葉酸 (Folate)
  • • 維生素 D

治療方法

藥物治療

鐵劑補充
  • • 口服鐵劑：硫酸亞鐵
  • • 注射鐵劑：嚴重缺鐵時使用
  • • 服用時間：空腹效果較佳
維生素補充
  • • 維生素 B12 注射
  • • 葉酸錠劑
  • • 綜合維生素

飲食調整

富含鐵質食物
  • • 紅肉、肝臟
  • • 深綠色蔬菜
  • • 豆類、堅果
促進鐵質吸收
  • • 維生素 C 食物
  • • 柑橘類水果
  • • 番茄、草莓
避免同時攝取
  • • 茶、咖啡
  • • 牛奶、起司
  • • 高纖維食物
